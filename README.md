# 教學訓練計畫主持人工作坊

依據「教學訓練計畫主持人工作坊.docx」製作的繁體中文視覺化網頁。

## 使用方式

直接以瀏覽器開啟 `index.html`，不需安裝套件或執行建置。HTML、CSS 與 JavaScript 全部包含於此單一檔案，沒有外部字型、圖片或程式相依性，也可放到 GitHub Pages 等靜態網站空間。

## 內容與功能

- 紫色漸層背景、emoji、響應式版面與活動聯絡資訊。
- 完整保留原文件日期（2026/01/25）、時間（9:00–16:00）、地點及 12 個職類選項。
- 姓名、機構名、職稱、職類、主持人身分、參與方式、Email、聯繫電話填寫與預覽。
- 必填及 Email 格式檢查、鍵盤操作、減少動態效果偏好支援。

此頁僅提供資料預覽，未連接報名收件服務，不會傳送資料，也未使用本機儲存。正式報名請聯繫原文件所載主辦單位。原文件未指定必填規則；本頁將所有填寫欄位設為必填，以便預覽完整資料。
